Diagnostics

Scans Firestore data for known anomalies — duplicate class schedules and duplicate ER room placements. Running a scan is read-only; cleanup is a separate, confirmed action.

Student Attendance Lookup

Shows every stored record from attendanceEvents and dailyAttendanceLogs for a student — every date, every code, including Learning Lab entries. (Present is not stored as a record.) Reports apply filters (date range, code, Learning Lab exclusion) before counting; this view skips all of that so you can see exactly what's stored. Records are read per student, not by scanning the collections.
